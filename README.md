Homebrew formula and cask for [Greed](https://github.com/johnae/greed), a fast, extensible modal
editor. Updated by Greed's release workflow whenever a release is published.

```sh
brew install johnae/greed/greed            # the greed command (macOS, Linux)
brew install --cask johnae/greed/greed-app # Greed.app (macOS)
```

`brew upgrade` picks up new releases.
